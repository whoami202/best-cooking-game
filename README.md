The Lantern Kitchen — an original 2D cooking game that plays offline in a desktop browser from static files. You are the chef of a tiny lantern-lit restaurant: take tickets, chop and cook ingredients, build dishes on the plating counter, and serve them before the guests' patience runs out.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in desktop Chrome — no build step, no network needed.
